# DevPilot — Local AI Debugger & Control Center

**DevPilot** — это легковесный локальный агент отладки и центр управления на чистом PHP (без тяжёлых фреймворков), предназначенный для автоматического сбора ошибок, анализа логов с помощью искусственного интеллекта (Gemini / OpenRouter), безопасного применения исправлений в коде, создания атомарных коммитов в Git и управления снимками баз данных[cite: 1, 4, 5, 7, 9, 10, 12].

## 📁 Структура проекта

```text
agent/
├── client/
│   └── index.html          # Веб-интерфейс панели управления (Dark Theme UI)
├── src/
│   ├── AI/
│   │   ├── Client.php      # Клиент для интеграции с Gemini API и OpenRouter
│   │   ├── Context.php     # Формирование системных промптов и контекста для ИИ[cite: 6]
│   │   └── DiffApplier.php # Безопасное применение предложенных ИИ правок к файлам
│   ├── Core/
│   │   ├── BrowserProbe.php# Проверка HTTP-состояния и зондирование ответа приложения
│   │   ├── DbSnapshot.php  # Управление резервными копиями и дампами БД (mysqldump / mysql)
│   │   ├── GitManager.php  # Обертка для автоматизации Git-операций через proc_open[cite: 9]
│   │   └── LogParser.php   # Фильтрация и парсинг логов ошибок выполнения
│   ├── Router.php          # REST API маршрутизатор (анализ, применение фиксов, откат)
│   └── debug_step.log      # Логи отладки выполнения шагов
├── config.json             # Основной конфигурационный файл[cite: 2]
├── config.example.json     # Шаблон конфигурации[cite: 3]
├── index.php               # Единая точка входа (Entry Point / Web UI / API)
└── README.md
```
🚀 Основные возможностиИнтерактивный Web UI (client/index.html): Удобная панель управления с выбором проекта, историей и интерфейсом диалога с ИИ.   

Двойная поддержка AI-провайдеров (src/AI/Client.php): 

Нативная поддержка Google Gemini API с авто-фоллбэком на OpenRouter[cite: 5].Интеллектуальный сбор контекста (src/Core/):

Парсинг логов с фильтрацией по проекту (LogParser.php)[cite: 11].Зондирование страниц через cURL (BrowserProbe.php)[cite: 4].

Автоматические снимки структуры и данных БД (DbSnapshot.php)[cite: 7].

Безопасное применение патчей (src/AI/DiffApplier.php): 

Автоматическая запись исправленного кода файлов целиком с созданием недостающих директорий[cite: 8].

Контроль версий и «Машина времени» (src/Core/GitManager.php, Router.php): 

Автоматическое создание атомарных коммитов при применении правок и полный откат кода вместе с базой данных (rollback).   

🛠 Установка и настройкаРазместите файлы проекта в корне вашего локального сервера (например, в директории домена разработки).Создайте рабочий конфигурационный файл на основе примера[cite: 10]:Bashcp config.example.json config.json

Откройте config.json и укажите ваши ключи API (Gemini / OpenRouter), а также параметры целевых проектов (пути к исходному коду, файлам логов и доступы к базам данных MySQL):
```text
JSON{
  "gemini_api_key": "YOUR_API_KEY",
  "log_window_seconds": 10,
  "projects": {
    "project": {
      "url": "http://cms/",
      "path": "E:\\server\\domains\\project\\",
      "git_path": "C:\\Program Files\\Git\\mingw64\\bin\\git.exe",
      "log_path": "E:\\server\\userdata\\logs\\PHP_8.1_error.log",
      "db": {
        "host": "127.0.0.1",
        "user": "root",
        "pass": "",
        "name": "cms_db"
      }
    }
  }
}
```
Убедитесь, что у веб-сервера есть права на запись в рабочие директории для ведения логов и создания скрытых папок снапшотов .devpilot/snapshots.🖥 ИспользованиеОткройте точку входа index.php вашего локального домена в браузере[cite: 10]. Выберите проект в выпадающем списке и нажмите кнопку «Проанализировать логи»[cite: 1]. Агент соберёт актуальные ошибки, отправит их модели вместе с контекстом окружения и выведет диагностику с готовыми вариантами правок.   При подтверждении изменений агент автоматически делает дамп БД, фиксирует изменения в Git и создает коммит[cite: 12].
